# ענדתי אושר

אתר קריאה אינטראקטיבי לספר "ענדתי אושר". כל קטע בספר הוא עמוד משלו.

- `index.html`: המעטפת, תוכן העניינים והניתוב.
- `stories/`: קטע אחד לכל קובץ. `kit.js` הוא הבסיס המשותף (עמוד גלילה, ספר מדפדף, צעדים).
- `build.sh`: בונה את `docs/`, שממנו GitHub Pages מגיש את האתר.

כל הזכויות על הטקסט שמורות למחבר.
